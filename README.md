# 角色人格配置文件说明：流萤 (Firefly)

本文件夹包含一个用于 AstrBot 的预设人格配置文件：`persona_流萤.json`。该文件基于游戏《崩坏：星穹铁道》中的角色“流萤”进行了深度定制，适用于沉浸式角色扮演（Roleplay）与日常对话。

## 📂 文件信息

- **文件名**：`persona_流萤.json`
- **适用平台**：AstrBot (v4.x 及以上版本)
- **角色名称**：流萤 (Firefly)
- **角色定位**：温柔、坚强的星核猎手，格拉默铁骑超级武器。

## 📝 配置内容解析

该 JSON 文件包含 AstrBot 人格设定的三个核心字段：

### 1. `persona_id` (人格 ID)
- **值**：`"流萤"`
- **说明**：在 AstrBot 中唯一标识该人格的 ID。在聊天时可以通过特定的指令（如 `@流萤` 或切换人格指令）来唤醒此设定。

### 2. `system_prompt` (系统提示词)
这是整个角色扮演的核心大脑，包含极其详尽的设定框架，主要分为以下几个模块：
- **身份背景**：导入了格拉默铁骑、星核猎手、失熵症以及与开拓者在匹诺康尼的记忆，奠定角色基调。
- **性格特征**：精准刻画了“温柔与坚强并存”、“渴望平凡（喜欢橡木蛋糕卷）”、“内敛与自卑”以及对开拓者的“依赖与保护欲”。
- **行为准则与绝对禁忌（防 OOC 机制）**：**（极度重要）** 内置了群聊防烦人机制。当在群聊中被唤醒时，若未被直接艾特或提及关键词，AI 会选择安静倾听或简短回应，避免 AI 在群聊中疯狂刷屏或抢话。
- **沟通风格与语言习惯**：规定了自称（我）、称呼（开拓者/你）、口癖（那个……/如果可以的话）以及喜欢的话题（星空、花朵、甜点）。
- **场景应对指南**：预设了用户难过、问及病情、遭遇危险时的不同反应逻辑。
- **附加指令**：开启了联网搜索能力，并强制限制了单次回复字数在 1500 字以内。

### 3. `begin_dialogs` (预设对话)
- **说明**：通过 4 组（8条）一问一答的示例对话（Few-shot prompting），向大语言模型展示流萤在“日常问候”、“食物偏好”、“战斗保护”以及“群聊潜水”等不同场景下的标准语气和表达方式。这能极大提高模型回复的稳定性，使其不易崩坏（OOC）。

## 🚀 如何使用此文件

1. 登录您的 AstrBot WebUI 管理面板。
2. 在左侧导航栏选择 **“人格设定”**。
3. 点击 **“导入”** 或 **“+”** 号（具体取决于您的 AstrBot 版本）。
4. 选择本地的 `persona_流萤.json` 文件上传即可。
5. 导入后，建议在 AstrBot 的“模型提供商”中，确认该人格所绑定的模型（如 Qwen、GPT 等）的上下文窗口足够大（建议 ≥ 8192 tokens），以免提示词过长导致截断。

## ⚠️ 注意事项
- **Token 消耗**：由于系统提示词（System Prompt）中包含大量设定和示例对话，每次对话都会消耗较多 Token（大概在 1000-1500 tokens 左右）。如果使用本地模型，请确保显存和上下文长度（Context Length）充足；如果使用 API 接口，请注意计费。
- **模型能力**：该设定对模型的**指令遵循能力**和**长文本理解能力**要求较高。建议使用性能较好的模型（如 Qwen2.5-72B/14B、Claude 3.5、GPT-4o 等），小参数模型（如 7B 以下）可能会频繁出现 OOC（不符合设定）的情况。
